# Design System

## Design Direction

The app should feel like a calm, immersive desktop productivity space.

Blend:

- Notion's simplicity and clarity
- Steam's dark visual language
- Discord Lofi Activity's relaxed focus-room mood
- Habitify Desktop's practical habit tracking density

The result should be motivating, polished, and quiet rather than flashy.

## Visual Principles

- Dark-first interface.
- High information density without clutter.
- Smooth, subtle animations.
- Clean typography.
- Strong hierarchy.
- Low-friction controls.
- Customizable appearance.
- Progress should feel rewarding, not stressful.

## Color Direction

- Default background: near-black or deep charcoal.
- Primary accent: customizable, with purple as the default reference.
- Secondary accent: blue for Flow Mode and calm focus states.
- Positive feedback: restrained green.
- Warnings or destructive actions: muted and sparing.

Avoid loud gradients, excessive glow, and high-saturation effects that distract from focus.

## Layout Direction

### Dashboard

- Desktop-first layout.
- Profile and progress should be immediately visible.
- Quick access cards should make major features easy to reach.
- Weekly activity and streaks should be scannable.
- Daily focus stats should be prominent but not overwhelming.
- Do not display user location anywhere on the dashboard.

### Focus Room

- Full, immersive focus environment.
- Timer should be the visual anchor.
- Music, ambient sounds, and background controls should stay accessible but secondary.
- Flow Mode should use a subtle blue glow around the timer.
- Avoid distracting celebrations during active focus.

### Habit Tracker

- Habits should be quick to complete.
- Weekly overview should be compact and readable.
- Contribution grid should show consistency at a glance.
- Streaks should encourage continuation without guilt.

## Typography

- Use clean, modern sans-serif typography.
- Prioritize readability over personality.
- Use large display text only for major dashboard numbers, timer values, and key progress moments.
- Keep labels concise.

## Components

Expected component patterns:

- Icon buttons for common actions.
- Compact cards for repeated feature summaries.
- Segmented controls for review periods or timer modes.
- Toggles for binary settings.
- Sliders or inputs for numeric preferences.
- Menus for theme, background, music, and ambient options.

Cards should be compact and purposeful. Avoid nesting cards inside other cards.

## Customization

Users should be able to customize:

- Background image
- Profile picture
- Primary accent color
- Theme

Defaults must look polished without customization.

## Motion

- Use subtle transitions for state changes.
- Avoid constant motion on productivity screens.
- Flow Mode animation should be calm and optional if motion settings are later added.

## Accessibility

- Maintain readable contrast.
- Do not rely on color alone to communicate state.
- Keep interactive targets comfortable for desktop use.
- Avoid text overlap and cramped controls.

## Content Tone

Use calm, direct language.

Prefer:

- "Start focus"
- "Review today"
- "Keep going"
- "Small wins count"

Avoid guilt-heavy, competitive, or overly intense language.
